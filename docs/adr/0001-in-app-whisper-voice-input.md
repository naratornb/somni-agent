# In-app voice input via bundled whisper.cpp, not macOS dictation

macOS system dictation (fn-fn) already types into any somni text field at zero cost, and it was the recommended default. We chose to build an in-app mic button backed by a locally run whisper.cpp `base.en` model anyway — downloaded on first use, not bundled in the installer — on every AI-adjacent text field, because voice capture is core to the Phase-2 "least-effort briefing" experience and should not depend on the user knowing/enabling an OS feature. Consequences: a native transcription dependency and its model distribution become ours to maintain, mic permission handling joins the entitlements surface, and transcription is English-only until the model choice is revisited. macOS dictation remains a working fallback in every field.
